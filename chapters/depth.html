Residual streams & MLPs

The same vector climbs all 96 layers, accumulating edits

a token's vector is never replaced on its way up — each block computes a small correction and adds it. by the top, the vector is the original embedding plus hundreds of stacked edits: early layers tend to add grammar, later ones add meaning-in-context and even predictions.

x ← x + Attention(x)     x ← x + MLP(x)

the straight line is the residual stream — each machine taps it, computes a correction, adds it back. a block with nothing to say adds ≈ 0, so 96-layer stacks still train. (LayerNorm re-standardizes before each tap — plumbing.)

Inside the MLP: expand, bend, contract

attention edited each vector using the other tokens; the MLP now transforms each vector alone — no information crosses between positions here. we pick up exactly where chapter 3 ended: X′ = the embeddings after attention's edit was added.

MLP(X′) = GELU(X′·Wup) · Wdown   4 dims → 8 neurons → 4 dims

expand: each column of Wup is a neuron — a learned pattern detector. its dot product with a token's vector asks: “how strongly is my pattern present in this word?” (real models use 4× the width: 12,288 dims → 49,152 neurons.)

bend: GELU is the gatekeeper — negative scores (“pattern not found”) are muted to ≈ 0; positive ones pass. this bend is the whole reason a deep network isn't just one big matrix.

contract: every neuron that stayed on votes on how to edit the token, through its row of Wdown. muted neurons contribute ≈ nothing — only detected patterns get a say. attention routes, MLPs know: real neurons fire for things like “basketball words” or “inside a URL”.

same rule as attention: add, never replace. X″ rolls on to the next block, where the whole dance — attention, then MLP — repeats.

Where the learned numbers live

of everything the vector passes through, the MLPs hold about two-thirds of all parameters — attention decides where information moves, but most of what the model knows is stored in MLP weights.
