The embedding matrix

Embedding = one giant lookup table

a dictionary where every definition is a list of numbers — and words with similar meanings get similar lists.

GPT-3's real table: 50,257 × 12,288 = 617M learned numbers before any thinking happens.

Problem: attention can't see word order

attention reads a bag of words, not a sentence — order has to be smuggled in.

“dog bites man”
=
“man bites dog”

The fix: add a position fingerprint

a clock with fast and slow hands: no two positions ever show the same combination.

inputi = WE[tokeni] + PE(i)

fast waves count nearby, slow waves count far — every position unique

Similarity = the dot product

meaning as geometry: the more two vectors point the same way, the more related the words.
